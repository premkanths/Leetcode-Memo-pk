# LeetCode Memory Hub Chrome Extension

A lightweight, dedicated browser extension that directly connects your active **LeetCode** session to your **LeetCode Memory Hub**, extracting your accepted solutions, exact code, runtime, and memory stats with zero console copy-pasting.

---

## 🚀 How to Install in 30 Seconds

1. Open **Google Chrome** (or Edge, Brave, Arc, Opera).
2. Go to `chrome://extensions/` in your address bar.
3. Turn on the **"Developer mode"** toggle in the top-right corner.
4. Click the **"Load unpacked"** button on the top-left.
5. Select this folder:
   ```
   D:\leetcode-memo\extension
   ```
6. The extension **"LeetCode Memory Hub Sync"** is now installed and ready!

---

## ⚡ How to Use

1. Click on the extension icon in your browser toolbar (pin it for quick access).
2. It will ask for your **User ID** and **LeetCode Username** (your User ID is easily copied with 1-click inside the Memory Hub **Sync Code** dialog).
3. Open any tab on [leetcode.com](https://leetcode.com).
4. Click **"⚡ Sync Now to Hub"** in the extension popup.
5. The extension will automatically extract your accepted solves and post them straight into your Memory Hub!
